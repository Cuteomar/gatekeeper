# 👥 Role‑Based Access Control (RBAC) System

A web application that demonstrates role‑based access control (RBAC). Users are assigned roles (admin, staff, guest) and permissions are enforced at the application level.

---

## 🚀 Features
- User authentication and role assignment  
- Role‑based permissions (admin, staff, guest)  
- Secure session management  
- Admin dashboard to manage roles and permissions  
- Audit logs for role changes  

---

## 📂 Project Structure
- `src/` → Python/Flask backend scripts  
- `templates/` → HTML/CSS frontend pages  
- `db/` → SQL schema for users and roles  
- `README.md` → Documentation
